Aperçu

Export

  • STL : maillage fermé en millimètres, axe Z vers le haut, prêt pour le slicer.
  • GLB : même modèle avec les couleurs, pour Blender, Windows 3D ou le web.

Les deux fichiers arrivent dans un seul .zip : ici, la page ne peut pas proposer un .stl ou un .glb directement.

Export jeu (Cosmos Colonies)

GLB texturé avec UV, sans socle, allégé : Y vers le haut, pieds à l’origine, face vers +Z, hauteur 1. Prêt pour la conversion du jeu (JSON + WebP).

Les vues doivent être chargées et la figurine générée au moins une fois pour vérifier le rendu.
